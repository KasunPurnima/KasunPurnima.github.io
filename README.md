# Kasun Purnima — Portfolio

A responsive personal portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — main page
- `style.css` — responsive design and animations
- `script.js` — navigation, scroll effects and reveal animations
- `assets/Kasun-Purnima-CV.pdf` — put your current CV here

## Before publishing
1. Replace `YOUR_EMAIL@example.com` with your real email address.
2. Replace the GitHub link with your GitHub profile.
3. Add your current CV as `assets/Kasun-Purnima-CV.pdf`.
4. Review project names/dates and adjust anything that differs from your final CV.

## GitHub Pages
Create a repository named `YOUR-USERNAME.github.io`, upload these files, then enable GitHub Pages from the repository's Pages settings.
